1. Run the Development Server
If the game isn't already running in your browser,

```
npm run dev
```

2. install Antigravity Browser Extension:
```
https://chromewebstore.google.com/detail/antigravity-browser-exten/eeijfnjmjelapkebgockoeaadonbchdd
```
Once started, open your browser to http://localhost:5173.
